# Mine Flowerz — เพิ่มรูปดอกไม้ 8 ช่อ

## เปิดใช้งาน

1. แตกไฟล์ ZIP ก่อนใช้งาน แล้วเปิด `index.html` เพื่อดูหน้าร้าน หรือ `admin.html` เพื่อจัดการสินค้า
2. วางไฟล์ HTML, CSS, JavaScript และโฟลเดอร์ `images` ไว้ด้วยกันตามโครงสร้างใน ZIP ห้ามย้ายเฉพาะ `index.html` ออกมา
3. ถ้าอัปขึ้น GitHub Pages ให้วางไฟล์ทั้งหมดในโฟลเดอร์ที่ตั้งค่าเป็นแหล่งเผยแพร่ โดยให้ `index.html` อยู่ที่รากของโฟลเดอร์นั้น พาธรูป `images/ชื่อไฟล์.webp` รองรับเว็บที่อยู่ในโฟลเดอร์ชื่อ repository

ไฟล์ที่จำเป็นสำหรับรูปชุดนี้คือ `catalog.js` และ `images/` รวมถึงไฟล์หน้าเว็บที่แก้แล้วในชุดนี้ แนะนำให้อัปเดตไฟล์โค้ดทั้งหมดจาก ZIP พร้อมกัน

ชื่อช่อใช้ตามชื่อไฟล์รูป และราคาตั้งเป็น `0` เพื่อให้เว็บแสดง “สอบถามราคา” สามารถแก้ชื่อ รายละเอียด ราคา และสินค้าแนะนำได้ในหลังบ้าน หรือแก้ค่าเริ่มต้นใน `catalog.js` ก่อนเปิดเว็บครั้งแรก

รูปจะแสดงทั้งการ์ดสินค้า ป๊อปอัปรายละเอียด หน้าจัดการสินค้า และตัวอย่างรูปตอนแก้สินค้า โดยคงสัดส่วนและแสดงภาพเต็มช่อ

## ข้อมูลเดิมในเบราว์เซอร์

เมื่อเปิดเว็บบนที่อยู่เดิม ระบบเพิ่มช่อใหม่ครั้งเดียว โดยเก็บสินค้า ราคา รูปที่เคยอัปโหลด การตั้งค่า และออเดอร์เดิมไว้ สินค้าที่มีชื่อตรงกับช่อใหม่จะได้รับรูปเมื่อยังไม่มีรูปเท่านั้น ไม่ต้องล้างข้อมูลเบราว์เซอร์ หากเคยมีสินค้าตัวอย่างเดิม สินค้าเหล่านั้นจะยังอยู่และสามารถซ่อนในหลังบ้านได้

หลังจากเพิ่มช่อแล้ว การแก้ราคาหรือลบสินค้าในหลังบ้านจะถูกจำไว้ การโหลดหน้าใหม่จะไม่เพิ่มสินค้าที่ลบไปกลับมา

## รันด้วย Node.js

ในโฟลเดอร์นี้ รัน `npm install` แล้ว `npm start` และเปิด `http://localhost:3000` เซิร์ฟเวอร์ถูกปรับให้ส่งไฟล์หน้าเว็บและรูปจากโครงสร้าง ZIP นี้ และใช้แค็ตตาล็อกรูปเดียวกันในการตั้งต้นฐานข้อมูล

หน้าเว็บและหลังบ้านชุดเดิมยังเก็บข้อมูลใน `localStorage` ของเบราว์เซอร์ และยังไม่ได้เรียก API ของ `server.js` การรัน Node.js จึงไม่ได้ทำให้ข้อมูลหน้าร้านซิงก์ข้ามเครื่องโดยอัตโนมัติ งานแก้ไขชุดนี้เพิ่มรูปและแก้ข้อผิดพลาดการโหลดหน้าเว็บเท่านั้น
